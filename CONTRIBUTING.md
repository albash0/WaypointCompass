# Contributing

Open an issue or pull request with a concrete change and how you validated it. Include your display/hardware profile for firmware issues. Run `sh WaypointCompass/tests/run_tests.sh` before submitting software changes. Report hardware checks separately from host simulations. Preserve third-party copyright notices and keep build outputs, credentials, private coordinates, device dumps and personal CAD history out of commits.

Contributions to original project files are made under GPL-2.0-or-later, matching the project license. Third-party files retain their existing terms.
